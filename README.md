# Gravity Wars

Turn-based tactical space artillery: aim, set power, and fire missiles that bend around planets' gravity; first to strip the opponent's hull wins the round. Around the match sits a free-to-play, cosmetics-only meta-game (account and per-ship progression, custom ship builder, battle pass, ranked seasons).

## Project facts

- **Engine:** Unity 2022.3.34f1 (`ProjectSettings/ProjectVersion.txt`) → C# 9. Built-in render pipeline, PhysX 3D physics on a Z-locked plane.
- **Packages:** Netcode for GameObjects 1.15 and Unity Gaming Services (authentication, cloud save, analytics, economy, leaderboards, lobby, relay) are installed but **inactive**; the `UNITY_NETCODE_GAMEOBJECTS` define is not set and must stay unset until the multiplayer milestone (it does not compile today, see the audit).
- **Playable today (editor only):** open `Assets/Scenes/HotSeat 1.unity` and press Play for a hotseat or bot match. The Build Settings scene list is wrong (see GDD §15 / audit G2); a player build cannot reach a match yet. Current milestone: **M1 – Playable build baseline**.
- **Controls (as coded):** ← → rotate · ↑ ↓ power (Shift fine) · M toggle fire/move · Space fire / move / detonate · 1 2 3 arm perk.
- **Content pipeline:** ScriptableObjects generated by *Tools → Gravity Wars → Generate Game Content / Quest Templates / Achievement Templates* into `Assets/Resources/…`. Edit the generators, not the generated assets.
- **Third-party packs (do not edit):** `Sci-Fi UI Collection`, `Sci-Fi UI`, `TextMesh Pro`, `LeanTween`, `StarSparrow`, `Planets of the Solar System 3D`, `Nebula Skyboxes`, `2D Space Kit`, `3Skyboxes`, `Honeti`. `Assets/Obsolete` is legacy code scheduled for deletion.
